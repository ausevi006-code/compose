
===== CREATE — POST /tasks =====
$ curl -X POST http://localhost:8080/tasks -H 'Content-Type: application/json' -d '{"title":"Сдать контрольную точку Compose","description":"API + PostgreSQL в Docker Compose","isDone":false}'
{"id":1,"title":"Сдать контрольную точку Compose","description":"API + PostgreSQL в Docker Compose","isDone":false,"createdAt":"2026-11-08T18:21:56.382132"}
Создана задача с id=1

$ curl -X POST http://localhost:8080/tasks -H 'Content-Type: application/json' -d '{"title":"Временная задача","description":"будет удалена"}'
{"id":2,"title":"Временная задача","description":"будет удалена","isDone":false,"createdAt":"2026-11-08T18:21:56.433206"}

===== DELETE — удаляем временную задачу =====
$ curl -X DELETE http://localhost:8080/tasks/2

HTTP 204


===== Проверка удаления — GET /tasks/2 (ожидается 404) =====
$ curl -X GET http://localhost:8080/tasks/2
{"error":"Задача 2 не найдена"}
HTTP 404


===== Проверка валидации — POST без title (ожидается 400) =====
$ curl -X POST http://localhost:8080/tasks -H 'Content-Type: application/json' -d '{"description":"без названия"}'
{"error":"Поле title обязательно"}
HTTP 400
